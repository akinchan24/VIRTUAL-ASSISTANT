# 🤖 AI Voice Assistant

A full-stack **MERN Stack AI-powered voice assistant** that allows users to create and customize their own AI assistant, interact through text or voice, and receive intelligent responses through speech.

## ✨ Features

- 🔐 User authentication with Sign Up & Sign In
- 🤖 AI-powered conversations
- 🎙️ Voice-based interaction
- 🔊 Spoken AI responses
- 🎨 Customizable AI assistant
- 💬 Interactive chat interface
- 👤 Personalized user experience
- 📱 Responsive and modern UI

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- REST API

### AI & Voice
- Google Gemini API
- Speech Recognition
- Text-to-Speech
